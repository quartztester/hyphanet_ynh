Freenet est un réseau pair-à-pair résistant à la censure : il stocke et route
des données chiffrées via ses pairs, et sert une interface web locale (« fproxy »)
pour consulter les freesites, les forums et la file d'envoi/réception.

Ce nœud tourne en mode OpenNet : il se connecte à des nœuds semences publics et
sa présence sur le réseau peut être observable. Les utilisateurs sensibles
devraient envisager le mode darknet (à configurer dans l'interface freenet,
section Security levels, après avoir ajouté des pairs de confiance).

Le premier démarrage initialise le magasin de données et se connecte au réseau ;
plusieurs minutes peuvent être nécessaires avant que les pages se chargent.
